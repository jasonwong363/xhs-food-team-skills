# Excel 模板库字段

工作簿固定包含“使用说明”“评论模板”“截流帖模板”“素人笔记模板”。第一列使用稳定记录 ID；每条记录保留单一原始来源。字段可按来源缺失留空，不得推测补齐。数据库中的长文本单元格开启换行；首行冻结并启用筛选。

## 使用说明

写明库版本/更新日期、各库用途、状态含义、来源字段解释、如何按 ID 调用，以及“模板不等于目标商家事实”。首次建库须写来源覆盖范围；增量更新需记录本次处理日期与新增数量。

## 评论模板

| 字段 | 用途 |
|---|---|
| 模板ID | 稳定编号，如 CMT-0001 |
| 模板角色 | A主评论 / B-E跟评 |
| 评论链ID | 可判断原评论是否属于同一评论链 |
| 原始评论 | 原文完整保留，不润色 |
| 评论功能 | 推荐、认同、补充体验、追问、种草意向等，有证据才标 |
| 正向依据 | 原话中支持保留的具体表达 |
| 到店证据 | 明确到店 / 明确未到店或未说明 / 不确定 |
| 复购证据 | 明确复购 / 未提及 / 不确定 |
| 提及实体 | 品牌、品类、产品、地点等 |
| 可替换实体 | 仅列语言结构上可替换的部分，不代表替换事实已成立 |
| 不可迁移信息 | 原作者经历、门店、价格、地址等事实限制 |
| 来源平台 | 如小红书 |
| 来源定位 | 原帖链接、截图文件名/页码、导出文件/工作表/行号等 |
| 发布时间/采集时间 | 来源显示什么就记录什么，并区分两者 |
| 互动快照 | 点赞/回复等原始显示值；缺失留空 |
| 审核状态 | 待确认 / 可调用 / 不入库 |
| 备注 | 歧义、上下文缺失等 |

正向库只放“待确认”或“可调用”候选；明确不正向的内容不写入此表。若用户要审阅完整筛除项，另经明确要求后另建审阅表。

## 用户确认案例库

当用户已经手动筛出并明确认为合理的 A/B/C/D/E 评论组合时，另建此表。该表用于后续优先调用，不替代原始评论模板表，也不把文案中的菜品、价格、地址或体验自动认定为官方事实。

| 字段 | 用途 |
|---|---|
| 案例ID | 稳定编号，如 QQLIB-0001 |
| 来源 | 用户粘贴、飞书表、截图或其它来源说明 |
| 原序号 | 原始列表中的顺序 |
| 评论A | 用户确认的 A 主评论原文 |
| 评论B | 用户确认的 B 跟评原文，可为空 |
| 评论C | 用户确认的 C 跟评原文，可为空 |
| 评论D | 用户确认的 D 跟评原文，可为空 |
| 评论E | 用户确认的 E 跟评原文，可为空 |
| 原始叠楼评论 | 保留 A-E 合并原文，换行不丢失 |
| 审核状态 | 通常为“用户手动确认”；不要改写为“官方确认” |
| 备注 | 适用项目、菜品事实边界、后续调用说明 |

## 截流帖模板

| 字段 | 用途 |
|---|---|
| 模板ID | 稳定编号，如 INT-0001 |
| 原始标题/封面文案 | 分别记录，来源未区分时注明 |
| 原始正文 | 原文完整保留，不润色 |
| 钩子类型 | 城市+品类提问、求推荐、选择困难等 |
| 需求人群/决策问题 | 仅记录文本明确呈现的信息 |
| 品类与地域词 | 原文实际出现的词 |
| 内容结构 | 按原文段落作用概括，不重写内容 |
| 评论承接点 | 原文提出的问题或邀请互动的位置 |
| 来源平台 | 平台名称 |
| 来源定位 | 链接或截图/文件行号等 |
| 发布时间/采集时间 | 分开记录 |
| 互动快照 | 原始可见指标，缺失留空 |
| 适配边界 | 不能迁移的品牌事实、地点、经历、承诺 |
| 审核状态 | 待确认 / 可调用 / 不入库 |
| 备注 | 待核实项 |

## 素人笔记模板

| 字段 | 用途 |
|---|---|
| 模板ID | 稳定编号，如 UGC-0001 |
| 原始标题 | 原文完整保留 |
| 原始正文 | 原文完整保留，不润色 |
| 到店体验证据 | 原文中明确的到店/点单/用餐依据，摘录或定位 |
| 用餐场景 | 仅按原文明确内容归类 |
| 产品/口碑点 | 原文明确提及的产品及感受 |
| 内容结构 | 原文段落作用概括 |
| 情绪与表达特征 | 描述源文本，不替用户改写 |
| 来源平台 | 平台名称 |
| 来源定位 | 链接或截图/文件行号等 |
| 发布时间/采集时间 | 分开记录 |
| 互动快照 | 原始可见指标，缺失留空 |
| 适配边界 | 不可移植的个人经历、商家事实和具体承诺 |
| 审核状态 | 待确认 / 可调用 / 不入库 |
| 备注 | 待核实项 |

## 来源与编号

新增记录优先沿用现有 ID 序列；首次建库按 CMT、INT、UGC 分别从 0001 编号。相同原文再次出现时不重复建记录，在备注或来源字段追加新的来源定位；近似表达保留独立记录。导入已有工作簿时先读取表头、ID 和记录，不覆盖已有数据。
