# 客户文案与改写约定模板

由客户负责人按实际资料填写；未知项标“待确认”，不编造。每个客户独立保存本文件。

- 客户名称、城市、门店范围：由客户资料填写。
- 基准日期、负责人、事实来源：记录菜单版本、官方资料或明确确认时间。
- 核心品类、主推单品：逐项记录标准菜名、做法、配料、证据和不确定项。
- 价格、营业时间、活动：只用有日期依据的数据；未确认不写。
- 标题长度：默认20个可见字符，客户另有要求则记录。
- 标题/正文品牌用法：分别说明保留、删除或替换。
- 标签：填写必带清单、可选清单、禁止清单；不要复制其他客户的标签。
- 个人经历处理：是否只做文字编辑，或要求逐项事实审核；不将原作者经历登记成门店事实。
- 禁写事项：未经营菜品、过期活动、无依据资质及位置关系等。
- 图片资料：原图目录、已核对分类库、确认过的菜名与照片对应关系。
- 已通过的笔记编号与批次：记录负责人确认；生成完成不等于审核通过。

## 冲突处理

当前明确确认优先；菜单或正式资料与评价冲突时保留差异并说明。只有同城市不代表同门店。原稿有菜名不代表目标门店有售，同名菜也要检查做法。
